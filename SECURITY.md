# Security Policy

This plugin is a security control, so vulnerabilities matter. Thank you for reporting them
responsibly.

## Supported versions

Only the latest version (the `main` branch, as installed by the DokuWiki Extension Manager)
receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use one of these private channels instead:

- GitHub: [Report a vulnerability](https://github.com/erkancinar/dokuwiki-plugin-turnstile/security/advisories/new)
- E-mail: erkancinar@gmail.com

Please include the DokuWiki version, the plugin configuration (without keys) and the steps to
reproduce. Reports are usually answered within a few days. Once a fix is released, the issue is
disclosed in the release notes and, if needed, on the
[plugin page](https://www.dokuwiki.org/plugin:turnstile).
